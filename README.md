# AbhayGutte_Task11
# Overview

Thala 7 is a responsive e-commerce website developed using HTML5 and CSS3. The website is designed to provide a clean and modern online shopping experience for footwear products. It includes a complete shopping flow from product browsing to checkout.

Features
-Home Page
-Modern hero section with featured product
-Promotional banner and call-to-action button
-Customer statistics section
-Responsive layout
-Product Details Page
-Product image gallery
-Product information and pricing
-Discount display
-Quantity selector
-Add to Cart button
-Breadcrumb navigation
-Shopping Cart Page
-Product listing with quantity controls
-Price calculation section
-Coupon code functionality UI
-Order summary card
-Secure payment indicators
-Checkout Page
-Contact details form
-Multiple payment method options
-Card Payment
-Crypto Payment
-Bank Transfer
-Order summary
-Secure payment section
